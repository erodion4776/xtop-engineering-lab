# XTOP Engineering Lab

A browser-based engineering laboratory project maintained by Ero Osarodion Odion.

The repository currently contains a standalone HTML application (`Index.html`). The interface and calculations should be reviewed in the source before relying on outputs for academic, design, or operational decisions.

## Getting started

1. Open the repository's [Index.html](Index.html) file.
2. Download or clone the repository.
3. Open `Index.html` in a modern web browser.
4. Follow the instructions provided within the application.

No Node.js package manifest is currently present in the repository root.

## Project notes

- Delivery format: standalone browser application.
- Main entry point: `Index.html`.
- Intended area: engineering and laboratory-oriented digital tools.
- Project status: experimental / evolving.

## Important

Verify formulas, units, assumptions, and numerical results independently before using the application for engineering decisions or formal reports. This repository is a software project, not a substitute for professional engineering review.
